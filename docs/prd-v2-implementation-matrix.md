### 可选运行时大模型增强

该能力不属于 PRD 强制项。默认配置 `VITAK_RUNTIME_LLM_ENABLED=false`；
当前本地 `.env` 已启用 `deepseek-chat` 且配置了非空 API Key，文档和报告中不得展示 Key。
启用后，DeepSeek/OpenAI 兼容模型只负责问题结构化解析和证据约束语言改写，
不是自由生成，也不能改变服务端确定的数据范围。

- 本地模型适配、DeepSeek 默认配置和前端模型状态已实现。
- 每条生成 Claim 必须复用确定性答案中的 Citation。
- 服务端校验未知证据、未支持数字、实体文本支持度和因果越界。
- 模型失败、超时或任一关键 Claim 未通过时整题回退确定性答案。
- API Key 不进入 GitHub Pages 构建；公开包扫描未发现密钥或私有来源。
- 离线契约测试 5 项通过；当前本地 DeepSeek 连通性探测和真实问答已通过，生成答案 5 条 Claim
  均通过证据核验并关联 4 条真实引用。
- 已验证个体化用药问题不会调用模型；超范围天气问题会直接拒答，不会使用无关证据生成答案。
- 科研负责人仍需对模型改写后的科学语义进行最终签认。
