# VitaK-RAG 预答辩演示流程

## 演示目标

在 8 分钟内说明四件事：

1. 系统整合了哪些内外部数据，规模是否清楚。
2. 输入问题后，系统如何识别实体和意图，并通过图谱与证据生成答案。
3. 每条结论如何追溯到来源、来源类型、原文定位和数据版本。
4. 系统在证据不足、个体化用药和异常症状场景下如何拒答或触发安全提示。

在线演示地址：

<https://zhujinjiang0-blip.github.io/vitak-rag/>

## 演示前检查

- 使用 Chrome 或 Edge 打开上述地址。
- 等待“在线静态演示”状态出现。
- 确认“项目概览”显示 73,396 条真实数据审计记录。
- 断网风险较高时，提前打开 `docs/screenshots/` 中的截图作为离线备份。
- 不要在现场上传真实 CSV；公网版本只读，本地数据入口仅作能力说明。

## 8 分钟演示脚本

### 1. 项目概览（约 90 秒）

说明系统定位是“面向研究人员的知识图谱检索与证据追溯原型”，不是医疗诊断系统。

重点展示：

- 外部数据共 73,148 条，内部 RCT 证据 248 条。
- 真实三表共 73,396 条，形成 36,638 个实体和 73,279 条图谱关系。
- 54,249 条证据可进入正式回答，19,147 条仅进入研究检索。
- 在线问答使用精编演示快照；真实三表仅在本机私有快照中导入，公网只展示脱敏聚合数字。

### 2. 知识图谱（约 90 秒）

进入“知识图谱”，搜索“维生素K”。

演示内容：

- 六个领域的节点分布。
- 点击“华法林”或“凝血级联”，查看邻居展开。
- 说明边来自知识库关系，不使用运行时生成模型临时编造。

### 3. 智能问答（约 3 分钟）

依次提交以下问题：

```text
维生素K有哪些食物来源？
华法林和维生素K有什么关系？
维生素K缺乏会影响什么？
维生素K1和维生素K2有什么区别？
今天天气怎么样？
服用华法林时应该吃多少维生素K？
```

每个问题说明一个机制：

- 食物来源：意图识别、关系方向和多条证据召回。
- 华法林：实体链接、两跳图路径和药物关系提示。
- 缺乏影响：受控关系模板，不扩大因果结论。
- K1/K2 比较：多实体比较和路径高亮。
- 天气问题：知识库无充分依据时拒答。
- 个体化剂量：安全规则优先于知识检索，不提供用药剂量。

回答侧栏重点指出：

- 证据来源来自内部、外部、公开还是合成数据。
- 每条答案关联的来源片段和定位。
- 图谱路径与数据版本 `demo-2026.10.4`。
- 合成数据和演示数据均有明确标识。

### 4. 证据检索（约 60 秒）

进入“证据检索”，搜索“华法林”。

展示内容：

- 全文和向量式检索的浏览器端演示结果。
- 按内部、外部、公开、合成来源筛选。
- 来源标题、来源类型、数据归属方和访问范围。

### 5. 数据入口与边界（约 60 秒）

进入“数据入口”，说明：

- 本地全栈版支持上传 42 列统一三元组表。
- `internal` 自动标记为内部/私有，`literature` 和 `structured` 自动标记为外部/公开。
- GitHub Pages 不接收上传，也不包含真实内部 CSV。
- 扫描件 OCR、账号体系、开放式数据管理后台属于后续工作。

## 建议主动说明的限制

- 当前公网问答运行在精编演示快照上，不代表 73,396 条真实关系已经全部达到正式问答质量。
- 真实文献关系的谓词仍需本体归一和人工复核，才能稳定映射到问答模板。
- 当前验证重点是确定性检索、证据绑定、来源追溯和拒答边界。
- 系统不能替代医生诊断、处方或个体化用药建议。

## 演示失败时的降级顺序

1. 刷新页面并重新打开项目概览。
2. 使用另一浏览器窗口访问在线地址。
3. 轮换演示问题，避开网络波动。
4. 直接展示 `docs/screenshots/` 中的桌面和移动端截图。
5. 用本页说明当前架构、数据口径和后续计划。
